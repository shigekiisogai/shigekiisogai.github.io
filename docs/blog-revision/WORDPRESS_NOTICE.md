# WordPress.com 移転案内と整理手順（本人用・未投稿）

新サイトが公開され、親担当が実URLを検収した**後**に、本人が操作してください。管理画面の表示名はプランや画面更新により異なる場合があります。旧個人サイト shigekiisogai.wordpress.com は、ホームを公開のまま残して移転先を案内します。

## ホームに載せる案内文

> 磯貝 茂樹 / Shigeki ISOGAI<br>
> https://shigekiisogai.github.io/

> My personal website has moved. Please visit the new website for current information about my research and teaching:<br>
> https://shigekiisogai.github.io/

## 順序と操作

1. WordPress.comの正規サイトから本人がログインし、下記のアカウント防御を確認。Tools／エクスポート等でサイトの控えを本人が保管し、必要なメディアも別途保存します。未使用メディアの網羅は未確認です。控えはpublic repoに入れません。
2. **新サイトの公開・実URL検収完了を確認**。WordPress.comの「固定ページ／Pages」からHomeを編集し、上記案内を掲載して公開のまま更新。固定ホーム設定を確認し、公開状態のホームから新URLが開くことをシークレットウィンドウで確認します。
3. 同じ「固定ページ／Pages」で下記13件を各々開き、設定の「公開状態／Visibility」で「非公開／Private」に変更して保存・更新します。画面に応じ、クイック編集や一括編集が使える場合もあります。**サイト全体ではなく各ページ**です。ページは直ちに削除しません。
4. ログアウトした状態でホームの案内と新サイトへのリンクを確認し、非公開にした旧URLも確認します。管理者としてログイン中は見えても一般閲覧者には見えません。

**学生への影響**：旧ページのURLをブックマークしている学生は、ページにより「見つかりません」等となり、本文を読めなくなります。新サイトへ自動転送されるわけではありません。授業中の学生には新URLを周知してから非公開化してください。旧URLを維持して案内文へ置き換える方法もあります。必要時には同じ公開状態設定を「公開」に戻せます。

## ログイン・管理の安全確認

- アカウントのSecurityで固有の強いパスワード、二段階認証、復旧メール・復旧コードを確認。パスワードや認証コードは共有しない。
- Usersで管理者を確認し、不要・不明な権限は内容を確かめてから削除。接続アプリとログイン中のセッションも確認し、不要な接続・不審なセッションを解除。
- 不要なフォーム・埋め込み・widgetをホームから外し、コメント設定を確認。プラグインやテーマを管理できるプランの場合のみ、不要なものを確認し、必要なものの更新を確認。
- ページを減らしてもアカウント侵害リスクは消えません。現状の二段階認証や接続アプリの設定は未確認です。

出典：既存 `site-cutover-audit-20261125/PLAN.md`・`PAGE_MAP.md`、[WordPress.com Security](https://wordpress.com/support/security/)、[Privacy settings](https://wordpress.com/support/privacy-settings/)。

## 旧ブログの非公開化（本人操作・未実施）

新サイトから削除したブログURL: https://sisogaiblog.wordpress.com/ （ソース表記は末尾スラッシュなし）。新サイトの再公開・実URL検収後、本人がWordPress.com dashboardで対象サイト **sisogaiblog.wordpress.com** を選択 → Settings → Reading → Site Visibility → Private → Save Changes の順に操作し、ログアウト状態で一般公開が終了したことを確認します。
